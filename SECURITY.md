# Security reporting

Do not post credentials, personal source URLs, browser profiles, private files or exploit data in public issues. Use GitHub's private vulnerability reporting feature when enabled on this repository. If it is unavailable, open an issue asking for a private reporting channel without disclosing the vulnerability or sensitive data.

Report the Framekeep version, supported Windows/Chrome version, affected component, expected boundary and a minimal synthetic reproduction. There is no guaranteed response time for this beta.

Framekeep accepts only its extension origin for native messaging. It does not read browser cookies or passwords. Private, DRM-protected, login-gated and unsupported sources may fail. Local previews are confined to the configured library and use an unguessable loopback capability. Do not share preview URLs. The public release contains no telemetry, cloud sync, automatic updater or bundled inference model.
