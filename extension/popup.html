Settings & help

A completion badge also stays on the toolbar until you view your downloads.

Transcripts

Available subtitles, including automatic captions, load when you check a video. These are the source platform’s captions, not a generated summary. Videos without captions need a separate speech-to-text service. Timestamp links open the video at that point on YouTube and Vimeo.

Supported platforms

Use a public video or post link. Availability varies by site and video.

Desktop app

Use Framekeep in its own Windows window. It shares the same save folder.

Local helper

If the helper needs setup, run Install Framekeep.cmd from the project folder, then Retry. It uses yt-dlp and FFmpeg; your browser cookies are not read.

Delete downloaded file?

This moves the file to the Windows Recycle Bin, where you can restore it. The file and its duplicate entries will disappear from this list.
