Organize and read

Use ＋ beside Collections, select library cards, then Organize selected.

Open a card using its preview or Open button. Double-click a title, press F2 while it is focused, or use its ellipsis menu to rename the display title. Transcript contains source, imported and generated text with separate track labels.

Browser connection & widget

Framekeep's installed component saves and processes files locally and connects the Chrome extension to that work.

In Chrome, pin Framekeep in the Extensions menu. Its toolbar popup can restore the bubble or change its visibility. Closing Desktop does not uninstall this component. If Chrome cannot connect, open Settings here and choose Check connection. Install Framekeep.cmd in your release folder is the setup route when the component is missing.

Transcript coverage

Source captions, imported files and generated tracks retain their own provenance.

Generated text may contain errors. A live recording covers only audio played after Start; gaps and source changes can make timestamps unsuitable for seeking or timed export. Processing details preserve original artifacts and review status.
